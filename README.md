B树的定义：

一棵 m 阶 B树满足以下条件：

- 每个节点最多有 m 个子节点
- 每个节点最多有 m-1 个键
- 所有节点（包括内部节点）都存储数据
- 所有叶子节点在同一层
- 键在节点内有序排列

B+树的定义：

一棵 m 阶 B+树在 B树基础上增加了以下规则：

- 内部节点只存键，不存数据，仅用于索引导航
- 所有数据只存在叶子节点
- 叶子节点之间用链表串联
- 内部节点的键会在叶子节点中重复出现
